# 8051-Microcontroller


A collection of 8051 microcontroller exercises and Embedded C programs focused on learning microcontroller programming, peripheral interfacing, and embedded systems development.

# About This Repository

I am a BS Electrical Engineering graduate from UET Peshawar and completed a two-month Embedded Systems Internship at Chip Soul Technology, where I worked with 8051 microcontrollers.

This repository organizes selected exercises and projects that I am permitted to share, along with code, explanations, and practical learning notes.

# Topics Covered

- 8051 microcontroller programming
- Embedded C programming
- GPIO and LED interfacing
- Timers and interrupts
- LCD and keypad interfacing
- Sensor and relay interfacing
- Hardware-software integration

Only retain topics for which you have actual code or documented exercises.

# Tools and Technologies

- C
- 8051-compatible microcontrollers
- Keil µVision IDE
- Embedded systems fundamentals

# Repository Structure

Each task is organized in a separate folder containing its source code and, where appropriate, a README with an explanation and hardware requirements.

# Learning Goals

- Improve my understanding of embedded C.
- Develop practical microcontroller programming skills.
- Learn to interface hardware peripherals.
- Document and organize projects using Git and GitHub.
